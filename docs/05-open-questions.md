# Open Questions

## Design Questions

- How detailed should tectonics be in the first playable version?
- Should the first version include life, or only climate and geology?
- How much direct control should the player have over catastrophic events?
- Should historical civilizations be modeled as abstract regions or as concrete entities?
- Should the UI be purely textual at first, or include a simple map view?

## Technical Questions

- What is the exact save format versioning strategy?
- What is the smallest useful tick size for the first simulation loop?
- Which data should be stored as source parameters versus derived measurements?
- What explanation format should the AI layer produce?
- What telemetry is needed for debugging and replay?

## Deferred Decisions

These should stay open until the simulation core is defined:

- multi-star support,
- advanced plate tectonics,
- detailed biosphere evolution,
- civilization depth,
- visual style,
- content pipeline for scenarios.
